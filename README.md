Description
This mod is a utility for players using Gigantic Coop and Barn, Ultimate Coop and Barn, Craftable Incubator or any other mod that allows for multiple incubators inside a single building! The mod will allow multiple eggs to hatch on the same day, allowing the player to name the animals as expected, or if the building is full, show the warning and return the eggs.

Installation instructions
Just drop it in your mods folder and you're good to go!
